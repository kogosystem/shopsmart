Recommendation evaluation

Temporal (time-split) test: the engine is given only purchases made BEFORE a split date, then we check how many of its recommendations the customer actually bought AFTER the split. The personalised engine is compared against a popular-products baseline on the same customers and the same top-N, so the comparison is fair.

How to read these
  • Precision = TP / (TP + FP): of what we recommended, how much was actually wanted.
  • Recall = TP / (TP + FN): of everything the customer later bought, how much we caught.
  • F1 = the balance (harmonic mean) of precision and recall.
  • No future purchases are used to generate the recommendations, so there is no data leakage.
