# ShopSmart Kenya

A Spring Boot 4.1.1 + Thymeleaf e-commerce web application whose research
contribution is a personalised product recommendation engine fed by real
shopping behaviour.

## Requirements
- JDK 21
- Maven (bundled with NetBeans)
- MySQL 8 + MySQL Workbench

## First run
1. In MySQL Workbench create the schema:  CREATE DATABASE shopsmart;
2. Open src/main/resources/application.properties and set your MySQL password.
3. Open the project in NetBeans (File -> Open Project) and run ShopSmartApplication.
4. Visit http://localhost:8080
